# ISU-CC-MAP

A GPS interactive map of Isabela State University - Cauayan Campus located in Cauayan City, Isabela, Philippines. This group project was done by Computer Science students from this university to fulfill the requirements of Creative and Critical Thinking subject.

---

## Libraries and Resources

ISU CC Map was developed with the help of the following open-source libraries and resources:
- Leaflet.js (v1.9.4) – Used for interactive map functionality, map layers, markers, and navigation.
- Leaflet EasyButton (v2) – Used to add custom interactive buttons to the map interface.
- GeoJSON Path Finder (v2) – Used for calculating walking routes through GeoJSON data.
- Font Awesome (v4.7.0) – Used for icons throughout the application.
- Google Inter Font Family – Used for the application's typography and interface design.

We sincerely acknowledge the developers and contributors of these projects for making their tools available to the community.
